# 第四课与前后课程的衔接

第四课共 **28 页，约 60 分钟**。从 Attention 的输出继续，讲解 FFN、激活函数、词表概率和采样，完成一次下一个 token 的预测过程。

| 课程 | 主要内容 | 与本课的关系 |
|---|---|---|
| 第一课 | token、向量、一次 Attention、两候选概率与贪心选择 | 提供加权汇总和预测的初步认识 |
| 第二课 | BPE、Embedding、位置、梯度与小型 bigram 实验 | 说明输入表示及参数更新 |
| 第三课 | Q/K/V 投影与完整单头因果 Attention | 本课继续展开多头汇合和 Block 后半部分 |
| 第四课 | FFN、激活函数、词表概率、采样与自回归 | 连接位置表示的变换与下一个 token 的选择 |
| 第五课 | 右移标签、CrossEntropy、梯度、优化器与验证 | 通过训练解释本课矩阵参数如何学习 |
| 后续生成课 | 解码策略、长序列与 KV Cache | 在基本采样和自回归循环上展开生成机制 |

本课介绍温度、top-k、top-p 和基本生成循环。训练推导与 KV Cache 分别在后续课程展开。

## 第四课的内容顺序

1. **第 1–4 页：Block 结构与输入。** 定位 FFN 和输出层；计算同一位置两个头的拼接与输出投影，说明 LayerNorm 的统计维度和残差路径。
2. **第 5–10 页：FFN 的计算。** 给定输入和矩阵，依次计算升维、ReLU、下投影；改变一个位置的输入，验证参数共享和逐位置计算。
3. **第 11–15 页：非线性与残差。** 用代数合并无激活的两层，再用数值说明 ReLU 的作用；介绍 GELU、SiLU 和 SwiGLU；计算 `h+FFN(Norm(h))`，对照代码与张量形状。
4. **第 16–23 页：词表分数与解码。** 计算 LM Head 和稳定 Softmax；固定同一分布，比较贪心、抽样、温度、top-k 和 top-p，并给出组合顺序。
5. **第 24–28 页：自回归与综合练习。** 将选出的 ID 追加到上下文，说明下一次前向计算及停止条件；区分生成与训练，并通过问题核对完整流程。

Notebook 按课件顺序安排 16 组实验，另有运算工具和可选 PyTorch 核对，共 18 个代码单元。

## 课堂完成后的检查标准

1. 给定输入和矩阵，能逐步算出升维、激活和下投影，并说明 FFN 输出在残差相加中的作用。
2. 能用代数与数值解释：没有激活时，两层仿射变换为什么可以合并。
3. 能区分归一化前的残差向量与进入 FFN 的向量。
4. 给定概率和随机数，能实际选择 token，并计算截断后的重新归一化。
5. 能在完整流程里指出最后表示、词表分数、概率与 token ID。
6. 能说明普通生成过程中上下文改变，而模型参数不因此更新。
