# Class 1 一页课程地图

**始终使用同一句前文：我 喜欢 喝。**

```text
① 文字变数字
“我 喜欢 喝”
 → ["我", "喜欢", "喝"]
 → [0, 1, 2]
 → [[1,0], [0,1], [1,1]]

② 混合上下文（只算“喝”这个位置）
Q=[1,1] 与三个 K 匹配
 → 分数约 [0.707,0.707,1.414]
 → 权重约 [0.248,0.248,0.503]
 → 对三个 V 加权混合
 → 新向量约 [0.752,0.752]

③ 预测下一项（演示限定两个候选）
新向量
 → 人工输出投影
 → “酒/牛奶”的分数约 [1.503,0.752]
 → 候选概率约 [0.680,0.320]
 → 选择“酒”
 → 新前文：“我 喜欢 喝 酒”
```

| 段落 | PPT 页码 | lesson.py / Notebook 步骤 | 应理解的事 |
| --- | --- | --- | --- |
| ① 文字变数字 | 3–5 | 1 | ID 是编号，embedding 是向量 |
| ② 混合上下文 | 6–11 | 2、3、4 + 遮罩实验 | Q/K 算权重，V 被混合，输出还是向量 |
| ③ 预测下一项 | 12–13 | 5 | 输出映射把向量变成候选分数，再选择 |
| 放回完整架构 | 14–15 | 只看图，按需展示 optional/ | 完整 Block 还有 FFN、残差、归一化，参数由训练得到 |
| 检查理解 | 16 | 改 V 的实验 | 解释数据流和改动，而非背术语 |

Softmax 在准备步骤 0 定义。所有步骤使用原始精度计算，仅在展示时四舍五入；不要把显示的三位小数代回计算，否则末位可能不同。

**最容易混淆的地方：**

|  | Attention 权重 | 输出概率 |
| --- | --- | --- |
| 给谁分配比例？ | 输入的各个位置 | 输出的候选 token |
| 用来做什么？ | 混合信息 | 选择下一 token |
| 本例数量 | 三个权重 | 两个候选概率 |

课堂演示采用人工参数、恒等 Q/K/V 投影，省略位置和其余 Block 组件，只演示一步。真实模型通常使用可学习参数，并对整个词表打分。
