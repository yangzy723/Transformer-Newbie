# Class 1：同一句前文，走通三个步骤

目标：解释“我 喜欢 喝”如何得到下一 token 的候选概率。课堂脚本用人工数字演示计算，没有训练完整模型。

## ① 文字怎样变成数字？

```text
我 喜欢 喝
 → ["我", "喜欢", "喝"]       # token：本课按空格切分
 → [0, 1, 2]                 # ID：查词表得到编号
 → [[1,0], [0,1], [1,1]]     # embedding：查表得到数字列表
```

编号只是查表地址，没有大小或语义含义。向量就是数字列表；本例每个位置两个数字。人工表便于手算，实际表由训练学习，真实 token 也可能是子词等单位。真实模型还会引入位置信息，区分词序。

## ② Attention 怎样利用前文？

先想象有比例 `[0.2,0.3,0.5]`：

```text
0.2×[1,0] + 0.3×[0,1] + 0.5×[1,1] = [0.7,0.8]
```

每个维度分别加权求和，得到新的向量。接着解决比例从哪里来：

1. **Q/K 匹配**：从最后一个位置“喝”的 Q=`[1,1]` 出发，与三个 K 分别点积（逐项相乘再求和）。
2. **分数变权重**：点积是 `[1,1,2]`，除以 √2，再做 Softmax。
3. **权重混合 V**：用得到的比例，对三个 V 加权求和。

```text
分数约 [0.707,0.707,1.414]
 → Softmax
 → 权重约 [0.248,0.248,0.503]
 → 加权混合 V
 → 输出向量约 [0.752,0.752]
```

本例 Q/K/V 使用恒等投影，数字可以相同，角色不同：Q/K 决定匹配，V 提供信息。实际模型一般会分别学习三个投影。Attention 输出是向量，尚不是一个词。

Softmax 将分数变成非负、总和为 1 的比例，较大的分数对应较大的比例。显示数经过四舍五入，可能加起来是 0.999，原始计算的权重之和为 1。

**因果遮罩**：最后一个输入位置可以看全部已给出的前文。如果换成第一个位置，后面两处是未来，分数设为负无穷，权重变成 `[1,0,0]`。当前位置可以看自己，因为要预测的是下一个 token。

## ③ 怎样从向量选出下一 token？

向量经过输出映射，得到各候选的原始分数，称为 logits。再用 Softmax 转成概率，选择一个 token 接回前文。

```text
混合向量约 [0.752,0.752]
 → 人工输出映射：[2×第一维, 第二维]
 → 酒/牛奶的分数约 [1.503,0.752]
 → 概率约 [0.680,0.320]
 → 选择酒
 → 我 喜欢 喝 酒
```

本例只比较两个候选；真实模型输出整个词表的 logits。这里的系数 2 是手动设置，不能说它来自训练。脚本只展示一次预测，真实生成会重复计算，并在结束条件满足时停止。

### 两次 Softmax，目的不同

|  | 第一次 | 第二次 |
| --- | --- | --- |
| 作用对象 | 各输入位置的匹配分数 | 各输出候选的分数 |
| 得到什么 | 混合权重 | 下一 token 的候选概率 |
| 本例 | 三个位置，三个权重 | 两个候选，两个概率 |

## 把这条链路放回真实架构

```text
token ID
 → embedding + 位置信息
 → Transformer Block（可以多层）
     Attention：跨位置混合
     FFN：逐位置加工
     残差、归一化：帮助信息传递和训练
 → 最终归一化 + 输出映射
 → 词表上的 logits
 → 概率 → 选择下一 token
```

这是文本生成的 decoder-only 主线。原始 Transformer 使用 Encoder–Decoder，其中 decoder 还有读取 encoder 输出的 cross-attention。

课堂脚本只实现三段核心接口，省略完整 Block 的其他组件。训练利用正确后续和误差学习参数；生成使用已有参数，不更新它们。多头、归一化和梯度的实现留到下一节。
