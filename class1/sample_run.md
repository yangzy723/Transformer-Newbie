## 数字分别代表什么？

- ID `[0,1,2]` 是输入 token 的编号。
- 三个 Attention 权重分配给三个输入位置，输出仍是向量。
- 两个候选概率分配给“酒”和“牛奶”，这里只比较这两个候选。
- embedding、恒等 Q/K/V 投影、输出系数都是人工设定；这里没有 loss 或参数更新。
