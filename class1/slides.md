## 03. 生成文本，先预测一个 token（5–8 分钟）

- 输入前文：我 喜欢 喝
- 输出：整个词表上的概率分布
- 选择一个 token，接回前文，再预测一次


> 示意概率：茶 0.60 · 牛奶 0.30 · 其他 0.10


**讲者备注**：这组概率是解释任务的人造例子，不是实测。词表是模型能输出的 token 集合。每个 token 都有一个候选概率，它们加起来为 1。生成选出的 token 会成为下一步的输入；整段回复是多步结果。


## 04. 训练有答案，生成要自己接着写（8–12 分钟）

> 训练可并行算多个位置；每个位置仍不能看未来。


**讲者备注**：展示 <bos> 我 喜欢 吃 苹果 。 <eos>。x 是前六个 token，y 是后六个 token。模型在“喜欢”位置预测“吃”，不是复述“喜欢”。完整句子在训练数据里，但因果遮罩禁止位置偷看未来。训练阶段有标签，生成阶段没有未来标签。


## 05. 第一步：文本 → token → ID（12–15 分钟）

- token 是切分后的单位，不保证等于一个字或一个词
- ID 是词表中的编号，不表示大小或语义
- 教学代码：按空格分词；真实模型常用子词切分


> 我 喜欢 喝 茶 → [7, 5, 6, 10]（本课词表）


**讲者备注**：运行脚本时先显示词表，以实际输出为准。ID 的数字顺序只是我们为复现结果排序得来；编号 11 不意味着茶比我重要。真实 tokenizer 可产生词、子词、字节等单位，本课不接入外部分词器。


## 06. Embedding：给每个 token 一排数字（15–18 分钟）

- 查表：一个 ID → 长度为 D 的向量
- 多个位置叠起来：X 的形状是 [T, D]
- 表里的数字是参数，会在训练中更新


> 向量像 [0.2, −0.7, 1.1, …]；某一维未必有固定含义。


**讲者备注**：用 Python 列表讲向量，用列表的列表讲矩阵。T 表示几个 token，D 表示每个 token 有多少个数字。本课 D=32。不要宣称某一维一定代表性别或词性；随机初始化的向量也还没有学到语言关系。


## 07. 位置：谁在前，谁在后？（18–20 分钟）

- “猫 追 狗”和“狗 追 猫”包含相同 token
- 本课把位置向量加到 token 向量上
- Attention 的因果遮罩还会限制可见位置


> X = token_embedding(ids) + position_embedding(positions)


**讲者备注**：普通的无位置、无遮罩自注意力不能区分任意重新排列带来的顺序信息；本课使用学习式位置向量表达位置，并用因果遮罩限制方向。原论文用正弦位置编码，现代模型也常有别的方式；本课不展开比较。


## 08. Attention 要解决：怎样利用上下文？（20–23 分钟）

- 一个位置的表示，需要结合其他可见位置
- 先算匹配分数，再把分数变成权重
- 按权重混合信息，得到新的向量


> Attention 输出的是向量，不是一个单词。


**讲者备注**：可以用‘查资料’类比：当前位置提出查询，各位置提供匹配依据和内容。随后立刻回到数字：它不是人类有意识地挑关键词，而是可学习的向量计算。最后选词需要经过后面的输出层。


## 09. Q、K、V：同一输入的三个变换（23–26 分钟）

- Q：当前位置拿什么去匹配
- K：各位置拿什么被匹配
- V：匹配以后，取回来什么信息


> Q = XWq，K = XWk，V = XWv（省略偏置）


**讲者备注**：Wq/Wk/Wv 是训练得到的参数矩阵。Q/K/V 都由同一序列 X 计算，所以叫 self-attention；不是三个独立句子。它们是类比中的角色，而不是保证每个维度有明确语义。演示一的人造 Q/K/V 跳过投影，演示二会真正学习投影。


## 10. 一个公式，读成三个动作（26–29 分钟）

- 匹配：QKᵀ / √dₖ → 分数矩阵
- 归一化：每行 softmax → 权重矩阵 A
- 混合：AV → 新的向量


> Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V


**讲者备注**：先演示两个列表逐项相乘再求和就是点积。T=3、d_k=2 时，Q/K 是 3×2，分数是 3×3，输出是 3×d_v。softmax 将一行分数变为和为 1 的权重；√d_k 缩放用于缓和高维点积的尺度。实现时 softmax 沿最后一个维度计算。


## 11. 手算一行：看到加权混合（29–32 分钟）

- q = [1, 0]，keys = [1, 0] / [0, 1] / [1, 1]
- 分数 ≈ [0.707, 0, 0.707]
- softmax ≈ [0.401, 0.198, 0.401]


> V = [[1, 0], [0, 2], [3, 1]] → 输出 ≈ [1.604, 0.797]


**讲者备注**：这里先不加因果遮罩。让同学算第一列输出：0.401×1 + 0.198×0 + 0.401×3 = 1.604。第二列同理。权重行上的三个值对应被读取的三个位置。所有数字均为演示用，不能解释成真实语言关系。

## 14. 一个 Block：混合上下文，再加工向量（38–41 分钟）

- 多头 Attention：不同投影，各算一份，再拼接
- FFN：对每个位置的向量做相同的非线性变换
- 残差相加与 LayerNorm：帮助信息传递和训练


> 本课：1 个 Block · 2 个 head · D=32 · 每头 16 维


**讲者备注**：指着本课 Pre-LN 示意解释：x + Attention(LN(x))，再 x + FFN(LN(x))。多头是同一层里的多个投影，层数是 Block 重复的次数；两者不要混淆。FFN 不在不同 token 之间直接交换信息。LayerNorm 今天只讲归一化的作用；不能省略它在本课图里的位置。


## 15. 架构全貌：把主线连起来（41–43 分钟）

- 原始 Transformer：Encoder–Decoder，用于序列到序列任务
- 今天的生成模型：Decoder-only，无跨注意力
- Block 可堆叠；末尾把向量映射为整个词表的分数


> ID → token+position embedding → Block → LN → logits → 概率


**讲者备注**：本课聚焦采用因果自注意力的 decoder-only 语言模型，不把所有大模型都归为这一种。原论文 decoder 还有读取 encoder 输出的 cross-attention；我们没有该模块。最后 Linear 输出 logits，softmax 用于生成概率；训练时 cross_entropy 接收原始 logits。
