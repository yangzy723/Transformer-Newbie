## 03. ① 文字变数字：先切分，再编号（6–9 分钟）

- 按空格切开：我 / 喜欢 / 喝
- 查词表：每个 token 对应一个 ID
- 编号用于查表，大小不代表词义


```python
tokens = text.split()
token_ids = [vocab[token] for token in tokens]
```


> 输入：我 喜欢 喝 → 输出：[0, 1, 2]


**讲者备注**：运行 split() 和查词表。把列表推导式读成逐个 token 查编号。真实 tokenizer 可以产生子词等单位，本课按空格切分便于观察。只理解用途，不背编号。


## 04. ① Embedding：编号换成数字列表（9–13 分钟）

- ID=0 查到 [1,0]，ID=1 查到 [0,1]
- ID=2 查到 [1,1]；每个位置有一个向量
- 本课只用 2 维；实际维度可大很多


```python
vectors = [embedding_table[i] for i in token_ids]
# [[1,0], [0,1], [1,1]]
```


> 到这里，文字已经变成可计算的数字。


**讲者备注**：向量就是数字列表。三个位置叠成 3×2 矩阵，不展开复杂张量。现场看 token、ID、vectors 三个输出。本例表人工设置，真实模型的表由训练更新；不要给某一维指定固定语义。

## 06. ② 先理解混合：每个位置贡献多少？（16–20 分钟）

- 假设三处贡献比例是 [0.2,0.3,0.5]
- 对每个数字分别加权求和
- 得到新向量；接着问：比例从哪来？


> 0.2×[1,0] + 0.3×[0,1] + 0.5×[1,1] = [0.7,0.8]


**讲者备注**：先手算第一维 0.2×1+0.3×0+0.5×1=0.7，第二维 0.8。此页比例人为指定，用于理解加权，不是脚本匹配得到的权重。下一步再算比例的来源。


## 07. ② Q / K / V：查询、匹配、取信息（20–24 分钟）

- Q：从“喝”发出的查询 [1,1]
- K：三个位置用来匹配的向量
- V：三个位置提供的待混合信息


```python
query = vectors[-1]
keys = vectors; values = vectors
```


> 本例三者用相同数字，角色不同；实际通常分别投影。


**讲者备注**：本例用恒等投影，Q 为最后一向量，K/V 为输入向量列表。实际有不同可学习线性投影。本课只算‘喝’这一行，不铺开整个矩阵。Q/K 决定权重，V 提供信息。


## 08. ② 匹配分数：逐项相乘，再相加（24–29 分钟）

- [1,1] 与 [1,0]：1×1 + 1×0 = 1
- 与 [0,1] 得 1；与 [1,1] 得 2
- 除以 √2，约为 [0.707,0.707,1.414]


```python
dot = query[0]*key[0] + query[1]*key[1]
score = dot / math.sqrt(2)
```


> 匹配分数还不是权重，也不需要加起来等于 1。


**讲者备注**：请同学计算后两项。循环就是对每个 key 做同一操作。√2 对应两维，控制分数尺度，不推导方差。先看点积，再运行 scores 单元。


## 09. ② Softmax：分数变成混合比例（29–33 分钟）

- 较大的分数会得到较大的权重
- 每个权重非负，总和为 1
- 得到约 [0.248,0.248,0.503]


```python
weights = softmax(scores)
# 每个位置一个权重；完整精度下和为 1
```


> 当前“喝”位置对三个可见位置各有一个混合权重。


**讲者备注**：先讲输入输出，再看 exp 结果除以总和。减去最大值用于数值稳定，不改变比例。第三处权重较大是人工数字的结果，不解释成真实词语重要性。显示数相加为 0.999 是四舍五入。


## 10. ② 用权重混合 V：Attention 就算完了（33–38 分钟）

- 第一维：0.248×1 + 0.248×0 + 0.503×1
- 第二维：0.248×0 + 0.248×1 + 0.503×1
- 新的向量约为 [0.752,0.752]


```python
mixed[0] += weights[i] * values[i][0]
mixed[1] += weights[i] * values[i][1]
```


> Attention 的输出是向量，还没有选出任何一个词。


**讲者备注**：从 [0,0] 逐项累加。运行并对照手算，细微误差来自显示取舍。有时间保持 Q/K 不变，只复制 V 并改第三项为 [3,1]，权重不变，输出约 [1.759,0.752]。不要原地改共享列表。


## 11. ② 预测下一项，不能提前看答案（38–42 分钟）

## 12. ③ 输出层：把向量变成候选概率（42–46 分钟）
