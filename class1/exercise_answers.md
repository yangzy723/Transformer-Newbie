# Class 1 参考答案（教师用）

## 只改 V

保持 Q/K 不变时，分数和权重都不变。第三个 V 从 [1,1] 改为 [3,1]：

```text
原权重约：[0.248,0.248,0.503]
原输出约：[0.752,0.752]
新输出约：[1.759,0.752]
```

第一维增加了约 `0.503×2`，第二维不变。使用新列表进行改动，避免同时修改共享的 K。

## 两次 Softmax

第一次把三个输入位置的匹配分数变成 Attention 权重，用于混合 V。第二次把两个输出候选的 logits 变成候选概率，用于选择下一 token。真实模型第二次针对整个词表，本例只演示两个候选。

## 数据流

```text
文本 → token → ID → embedding
 → Q/K 匹配 → 权重 → 加权 V → 新向量
 → 输出映射 → logits → 候选概率 → 下一 token
```

完整架构还要加入位置信息、FFN、残差、归一化等组件，课堂演示并未完整实现。

## 训练和生成

训练根据标签与误差调整参数。生成使用已经确定的参数，选择结果接回前文，使输入变长。课堂演示人工设定参数，没有发生训练。

## 因果遮罩

第一位置只能看自己，未来分数设成负无穷，Softmax 权重为 [1,0,0]。最后一个已知输入位置可以看全部已给出的前文；它要预测的是尚未出现的下一 token。
