# Class 1 练习参考答案（教师用）

## 只改 V

权重不变：`A = softmax(QKᵀ/√dₖ)` 的计算没有用到 V。输出变化：`O=AV` 用到了 V。把 `V[2]` 从 `[3,1]` 改成 `[30,10]`，无遮罩时第一行输出从约 `[1.604,0.797]` 变成约 `[12.434,4.407]`。

强调权重与最终输出是两种不同的东西。

## 因果 mask 与未来 V

未来位置的权重是 0，因此该位置的 V 不影响前面的输出。改第三个位置的 V，第一个和第二个位置的输出都不变，第三个位置的输出可变化。本课自动检查验证了这一点，也验证了完整模型里改变未来输入 token 不会改变更早位置的 logits。

## 改 prompt

`我 喜欢` 后可有吃、喝；`我 喜欢 吃` 后可有苹果、香蕉；`你 喜欢 喝` 后可有茶、牛奶。实际概率接近哪一种，看运行输出，不要求唯一句子。每次追加 token 后，下一步都以更长的已生成上下文作为输入。

词表外的 token 会报错，输入需按空格切开。本课的贪心生成给定同一模型和输入会重复，但不同版本训练后的微小差异可能改变近似并列候选的排序。

## 概念验收

- ID 是编号；embedding 是可学习的向量。
- Q/K 决定权重；V 是要混合的信息；self-attention 中三者来自同一序列。
- Attention 输出向量；输出线性层产生词表上的 logits；softmax 产生概率。
- 多头是同一层的不同投影，层数是 Block 重复次数。
- 当前位置可以看自己，因为目标是预测右边的 token。
- 训练更新参数；生成不更新参数，只改变上下文。
- loss 下降仅证明这组训练数据上拟合更好；没有验证集便没有泛化评估。

## 为什么训练 loss 可能停在约 0.35？（老师补充，课内不要求）

八句等频句子的 `<bos>` 后有“我/你”，`喜欢`后有“吃/喝”，`吃/喝`后各有两种食物/饮料。每句 6 个目标位置，其中 3 个位置的最优条件分布有两个等可能候选。这个人工训练集的理想平均交叉熵约为 `3 × ln(2) / 6 ≈ 0.3466`。其余三个位置可接近确定。

这是有多种合法后续带来的条件不确定性，不能简单解释成训练失败；也不能因此断言模型学到了通用语言知识。
