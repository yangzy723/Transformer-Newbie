# Class 1 教师讲稿：60 分钟带同学走通 Transformer

## 本课的讲法

围绕一个问题：**“我 喜欢 喝”之后，模型怎样决定写什么？** 讲完数据流，再回到模型全貌。面对没学过深度学习的同学，先用列表、查表、加权平均建立直觉，然后对应公式和代码。

下课验收：同学能画出 `文本 → token ID → 向量+位置 → 因果 Attention/FFN → logits → 下一 token`，能解释 Attention 输出向量，并能区分训练更新参数和生成读取参数。不要把“听过所有组件名”当作理解。

## 课前准备（不占用这 60 分钟）

1. 打开 [PPT](class1_transformer.pptx)，熟悉每页讲者备注；投影使用 16:9。
2. 按 [README](README.md#运行方法) 安装依赖，选好 Notebook 内核。先运行两次 Attention、200 步训练和 `check_demo.py`。
3. 打开 [demo.ipynb](demo.ipynb)，放大字体。预留终端备用，不把安装依赖变成课程主体。
4. 准备一张纸或白板。板书只需要一句例句、Q/K/V、Attention 公式、最终数据流。
5. 准备 [sample_run.md](sample_run.md) 和 Notebook 中已经执行的输出。若现场环境有问题，零依赖 Attention 仍可运行。

## 0–5 分钟｜先让同学体验预测（PPT 1–2）

**开场（2 分钟）**：“我喜欢喝____，你会填什么？”让同学给出至少两个候选，追问为何某些词更合理。

承接：“我们在利用前面的文字。机器会对候选 token 给出一组概率，然后挑一个接回前文。今天把这个过程用数字和代码拆开。”不要说模型每次都只输出一个汉字；先用熟悉的词作例子，后面引入 token。

**目标与基础（3 分钟）**：请同学解释 Python 列表 `[0.2, 0.7]` 和二维列表 `[[0.2, 0.7], [0.1, 0.3]]`。接下来把它们叫向量和矩阵，不预设他已经学过线性代数。

说明今天的三个成果：画数据流、解释 Attention、运行一次训练与生成。优化器和梯度先认识功能。

## 5–12 分钟｜模型的任务和学习方式（PPT 3–4）

**下一 token（3 分钟）**：板书 `我 喜欢 喝 → 茶/牛奶/其他`。示意概率 0.60/0.30/0.10 是人工解释数字；它们不是模型实测。强调每一步会对**整个词表**打分。选出的 token 接回输入，再预测下一个。

**训练和生成（4 分钟）**：写出一整句，按位置上下对齐：

```text
完整：<bos> 我    喜欢  吃    苹果  。    <eos>
x：   <bos> 我    喜欢  吃    苹果  。
y：   我    喜欢  吃    苹果  。    <eos>
```

逐列解释：“看到 `<bos>`，目标是预测‘我’；看到‘我’，目标是‘喜欢’。”训练有完整句子的标签，模型计算预测误差、调整参数。生成没有未来的标签，必须自己一步一步往后接。

提问：“输入位置是‘喜欢’，这一列应该预测‘喜欢’还是‘吃’？”预期：吃。训练虽然可以同时算所有位置，但必须遮挡未来，不能偷看标签。

## 12–20 分钟｜让文字成为数字（PPT 5–7）

**分词与 ID（3 分钟）**：用本课空格分词的例子演示 `"我 喜欢 喝 茶".split()`。ID 是编号，数值没有语义大小。真实模型的 token 可能是子词等单位，本课人工切分只是便于读代码。用脚本的实际词表对应，不要求背编号。

**Embedding（3 分钟）**：“把每个编号换成长度为 32 的数字列表。8 个句子、每句 6 个位置，变成 `[8, 6, 32]`。”Embedding 是可以更新的查找表；这些数字初始随机，不是人手写入的语言规则。某一维未必对应明确的词性或属性。

**位置（2 分钟）**：对比“猫追狗”和“狗追猫”。本课在 token 向量上加位置向量。位置向量和因果遮罩各有作用：前者表达位置，后者限定可见范围。不要说所有模型一定都用相加的位置编码。

检查：“ID 和 embedding 向量有何区别？”预期：一个是编号，一个是可学习的数字表示。

## 20–35 分钟｜把 Attention 算出来（PPT 8–12）

**作用（3 分钟）**：“每个位置需要利用其他位置的信息。我们先算它和各位置的匹配程度，再按权重混合信息。”输出仍是向量，选词是后面的步骤。

**Q/K/V（3 分钟）**：用查资料作短类比：query 是当前要查的条件，key 是索引，value 是取回的信息。随后对应 `Q=XWq, K=XWk, V=XWv`，说明 W 是参数，self-attention 的三者来自同一序列。别把类比当成真实心理过程。

**公式（3 分钟）**：只读三个动作：

```text
分数 = QKᵀ / √dₖ
权重 = softmax(分数)      # 沿每行，权重之和为 1
输出 = 权重 @ V          # 对 V 的加权混合
```

先让同学算 `[1, 0]` 与 `[1, 1]` 的点积。缩放先讲“控制点积的尺度”，不推导方差。softmax 用于把分数变成权重，最大的分数对应最大的权重。

**手算（3 分钟）**：用第一页 query：

```text
q = [1, 0]
K = [[1, 0], [0, 1], [1, 1]]
V = [[1, 0], [0, 2], [3, 1]]
分数 ≈ [0.707, 0, 0.707]
权重 ≈ [0.401, 0.198, 0.401]
输出 ≈ [1.604, 0.797]
```

请同学计算输出的第一维，第二维由老师示范。这些 Q/K/V 是人为指定的矩阵，不是训练出来的中文表示，不据此解释“我”是否关注“猫”。

**运行和改动（3 分钟）**：运行终端或 Notebook 的 Attention 单元。

```bash
python3 class1/code/attention_demo.py
```

只讲 `attention()` 里的点积、softmax、加权和，跳过命令行和 SVG 辅助代码。让同学预测：只把 `V[2]` 改成 `[30, 10]`，权重会改变吗？运行 Notebook 的对应单元，解释权重不变、输出变化。时间够再改 Q/K。

## 35–43 分钟｜遮罩与 Block，回到全貌（PPT 13–15）

**因果遮罩（3 分钟）**：运行：

```bash
python3 class1/code/attention_demo.py --causal
```

请同学比较第一行。遮罩的上三角是未来位置，先设成负无穷，再做 softmax，于是权重成为 0。第一行 `[1, 0, 0]` 因为只能读自己；位置输入是已知的，它预测的是下一个 token。

**Block（3 分钟）**：按图走：

```text
x = x + Attention(LayerNorm(x))
x = x + FFN(LayerNorm(x))
```

多头是在不同投影下做多份 Attention，拼接并再次投影。本课 2 头、每头 16 维；两头不是两层。FFN 在每个位置上做相同的非线性变换；跨位置的信息交换来自 Attention。残差保留原有信息，LayerNorm 帮助稳定表示的尺度。本课使用 Pre-LN，原论文图采用 Post-LN，不混画两种。

**全貌（2 分钟）**：在图上连起 `ID → token+position → Block → 最终 LN → 输出 Linear`。输出 Linear 得到词表上的原始分数 logits；生成时 softmax 把分数变成概率。

说明原始 Transformer 包含 Encoder 和 Decoder，decoder 还有读取 encoder 输出的 cross-attention。本课聚焦文本生成常见的 decoder-only，只有因果 self-attention，没有 cross-attention。不是所有大模型都属于这一类。

## 43–55 分钟｜真正训练与生成（PPT 16–19）

**输入和形状（3 分钟）**：运行 Notebook 数据和 forward 单元，看 `x[0]`、`y[0]`。打印形状，让同学解释每一维。终端可用：

```bash
python class1/code/tiny_transformer.py --steps 200
```

八句人工语料等长，无需 padding。输入 `[8,6]`；嵌入 `[8,6,32]`；logits `[8,6,12]`；权重 `[8,2,6,6]`。词表含 10 个普通 token 和 2 个起止标记。

**训练与 loss（3 分钟）**：在代码中只展开四行：前向计算、`cross_entropy`、`backward()`、`optimizer.step()`。交叉熵衡量正确 token 被赋予的概率：单个位置可以直观写成 `−log p(正确 token)`。参数更新让整体误差变小。

训练时把**原始 logits**传给交叉熵，不先做 softmax。展示实际日志，不预设同学设备的耗时。纯 CPU，模型很小；第一次导入 PyTorch 可能比训练更慢。

**逐步生成（3 分钟）**：比较训练前后，再读 `trace` 输出。生成取最后一个位置的 logits，softmax，再挑最高概率 token；接回前文、继续预测，遇到 `<eos>` 结束。本课用贪心选择，大模型还可用采样策略。

提问：“生成过程中也会执行 `optimizer.step()` 吗？”预期：不会。参数没有变，变化的是输入上下文。

**结果边界和改 prompt（3 分钟）**：用 `你 喜欢 喝` 或 `我 喜欢 吃` 做实验。现有语料里合法后续不止一个，没必要指定“茶”必须成为第一名。训练集有歧义前缀，所以 loss 也不必接近 0。

强调：这里只显示对八句话的训练集拟合，无验证集；不能推断泛化或“已经理解语言”。词表外词会报错，属于本课 tokenizer 的限制。Attention 权重不直接等于人的解释。

## 55–60 分钟｜让同学自己串起来（PPT 20–21）

**检查理解（3 分钟）**：不要让同学只回答“听懂了”。问：

1. Attention 输出是什么？——向量，是信息的加权混合。
2. 第一行因果权重为何是 `[1,0,0]`？——第一个位置只能读到自己。
3. 生成一个 token 会更新模型参数吗？——不会，训练才更新。

让同学自己画完整链路；如果能解释每一个箭头，就达到本节目标。答错时回到相应图或运行输出。

**课后（2 分钟）**：先预测再实验：改 V，改合法 prompt，记录输出；画数据流并标注形状。预计 20–30 分钟。参考答案单独放在 [exercise_answers.md](exercise_answers.md)。

## 节奏调整和现场预案

| 情况 | 处理 |
| --- | --- |
| 到第 20 分钟仍在 embedding | 用“数字列表 + 查表”收束，不增加距离或向量空间知识；保留后面的 Attention 实验 |
| 同学看不懂矩阵乘法 | 只手算第一行的第一维，用加权平均解释输出，其余交给程序 |
| PyTorch 未安装或环境失败 | 运行零依赖 Attention；用已执行 Notebook 和 sample_run 展示训练，不把缓存输出当现场结果 |
| 小模型生成的句子和 PPT 示意不同 | 查看逐步候选：语料有多个合法后续，说明贪心路径可能变化 |
| 未知 token 报错 | 检查空格，用 `我 喜欢` / `你 喜欢 喝` 等已知 token；本课没有未知词回退 |
| 训练用了超过一分钟 | 切换到已经执行的输出，课后定位环境；默认不临时换 GPU 或下载大模型 |
| 时间超出 | 减少 FFN/LayerNorm 细节和第二次 prompt 实验；保留手算、一次训练与最后检查 |

本节先不展开：反向传播推导、位置编码的各种实现、复杂采样策略、KV cache、微调、分布式训练。下一节可以让同学用 PyTorch 重写多头 Attention，理解维度变换，再深入梯度与 loss。
