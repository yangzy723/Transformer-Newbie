# 第三课：重新走进 Transformer，理解 Attention


## 01．输入一句话，模型怎样继续写？（0–3分钟）

从“我喜欢喝”回到前两课：已有的输入，怎样变成下一个 token 的概率。
- 最后位置的向量用于计算下一个token的词表分数。
- 第一课两候选例：酒/牛奶概率约0.680/0.320。
- 复习分词、向量、位置，再展开Attention怎样读取上下文。

> 今天要看清：一个 token 的向量怎样吸收上下文。

**讲者备注**：让同学给两个合理续写，再问模型需要输出什么。预期：词表候选分数、概率，再选择ID。把记得的术语放回流程图。 课堂安排留在讲稿：前25分钟复习、后半节计算并修改Attention。用最后位置的向量引出它如何包含前文。

## 02．从文字到下一个 token（3–5分钟）

分词和查表负责输入，Block 更新向量，LM Head 把向量变成词表分数。
- Tokenizer产生ID，Embedding查成向量。
- Block逐层更新各位置的表示。
- 最终Norm和LM Head得到词表分数。

> Attention 位于 Block 内，输入和输出都是向量序列。

**讲者备注**：沿左列读生成过程，再展开右侧一个Pre-Norm Block。两条残差分别保留x与h，RoPE在Q/K上。问Attention后是否已经是概率，预期仍是向量。B批量、T位置数、D宽度。

## 03．三个向量，怎样合成一个向量？（5–9分钟）

重看第一课的算例：当前查询给每个位置一个权重，再把 V 加权相加。
- 旧例V为[1,0]、[0,1]、[1,1]。
- 权重约[0.248,0.248,0.503]。
- 汇总得到约[0.752,0.752]。

> Attention 按内容相关的权重，汇总各位置提供的 V。

**讲者备注**：请学生算一维。权重大不等于直接复制该V，仍混合全部V。显示权重四舍五入后和可能0.999，完整精度计算输出为0.7517449；显示为0.752。

$$
\mathbf z=\sum_j a_j\mathbf v_j
$$

## 04．两次 Softmax，用在两个地方（9–12分钟）

同样是把分数归一化，但参与归一化的对象不同。
- Attention在输入位置之间分配读取权重。
- LM Head后在候选token间分配预测概率。
- 旧例酒/牛奶概率约0.680/0.320。

> 注意力权重面向输入位置；预测概率面向词表。

**讲者备注**：问0.503与0.680面对什么对象。两处dim=-1的轴含义不同。酒/牛奶来自第一课两候选人工参数，真实LM Head面向全词表。 过渡：输出端看过了，再回到这句话如何进入模型，复习第二课的分词与查表。

## 05．BPE 训练：合并之后重新计数（12–15分钟）

频次来自当前的相邻片段；合并以后，相邻片段也跟着变化。
- 5、3、2次语料里喜+欢共10次。
- 合并后我+喜、欢+喝等旧组合消失。
- 我+喜欢、喜欢+喝等新组合进入统计。

> 每轮：统计当前相邻对 → 选择 → 合并 → 重新统计。

**讲者备注**：问喜+欢为什么不是3次。请学生圈出合并后新增和消失的相邻对。教学实现每轮清空Counter；同频按固定遍历顺序选择。实际实现也可增量维护计数。

## 06．BPE 编码：按已有规则继续合并（15–18分钟）

训练得到规则；编码时只执行规则，直到当前没有可用的合并。
- rank0先合并喜+欢。
- 后续规则继续形成喜欢喝奶茶。
- 最终你/喜欢喝奶茶，共两个token。

> 当前相邻候选中，优先执行最小的可用 rank。

**讲者备注**：逐行执行冻结的四条规则。问得到喜欢后为什么不停，预期仍有当前可用规则。编码不重训频率。字符教学例的ID与真实ByteLevel配置分开。

## 07．ID 是行号，Embedding 是可训练的表（18–21分钟）

ID 决定取哪一行，预测误差决定这一行的数值怎样更新。
- 冻结320词表配置编码得到[300,304,262]，查E相应行形成[3,D]输入。
- 第二课二维小表第1行参数[0.2,-0.1]，累计梯度[1,2]。
- 学习率0.1，SGD更新后得到[0.1,-0.3]。

> Embedding 查表提供输入表示，训练更新表中的数值。

**讲者备注**：用冻结320配置的我喜欢喝牛奶。→[300,304,262]查行。问backward会不会立即更新，预期step才更新。第二课真实bigram loss5.7565→0.3559。重复ID的上游梯度累加到同一行。 右侧是第二课独立二维小表，不能把它当成左侧320行参数表。第1行梯度由重复ID的两次读取累加得到。

$$
\mathbf X=\mathbf E[I]
$$

## 08．内容相同，位置不同（21–25分钟）

相加式编码改变输入；RoPE 在 Q/K 匹配时引入相对位置关系。
- 相加式：内容向量加位置向量。
- RoPE：Q/K成对分量按位置旋转。
- 两支箭头一起移位，相对转角保持。

> 相加式编码修改输入；RoPE 通过旋转 Q/K 加入位置关系。

**讲者备注**：位置按token序号。左侧E+P，P可学习或由sin/cos产生。右侧初始q=k=[1,0]、每格30度，位置1/3与3/5夹角都60度，点积0.5。真实RoPE用多频率和弧度，V保留。主手算先隔离位置，Notebook最后接回实际RoPE。

$$
\theta_{p,i}=p\omega_i
$$

## 09．Q、K、V 分别负责什么？（25–28分钟）

把“如何匹配”和“汇总什么”分开，让两件事分别学习。
- Q用于发起匹配。
- K提供可匹配的特征。
- V提供实际汇总的信息。

> Q/K 决定匹配分数，V 提供被加权汇总的内容。

**讲者备注**：从同一X分三路，问只改V会否改变QK点积，先预测后实验。W是训练参数，注意力权重随输入动态计算。名称表示计算角色，不给每一维指定语言学含义。

$$
\mathbf Q=\mathbf X\mathbf W_Q,\quad\mathbf K=\mathbf X\mathbf W_K,\quad\mathbf V=\mathbf X\mathbf W_V
$$

```python
q, k, v = project(x)
```

## 10．从 X 算出 Q、K、V（28–32分钟）

从这里换用本节的三张投影矩阵，后面的计算一直沿用同一组数值。
- X三行[1,0]、[0,1]、[1,1]。
- Q=X@W_Q，K=X@W_K，V=X@W_V。
- 喝的V=[3,-1]。

> 线性投影重组输入特征，得到用于匹配与汇总的表示。

**讲者备注**：从旧例切换新矩阵。W_Q=[[1,0],[0,2]]，W_K=[[1,1],[0,1]]，W_V=[[1,-1],[2,0]]。请学生计算最后一行V。Q/K最后一行恰巧相同，不表示投影相同。这里X@W；nn.Linear存weight为[out,in]，用X@weight.T。

```python
q = x @ w_q
k = x @ w_k
v = x @ w_v
```

## 11．“喝”与每个位置分别算一个分数（32–35分钟）

拿一个查询向量与三个 K 做点积，先得到一行原始分数。
- “喝”的Q=[1,2]。
- 依次与K的三行[1,1]、[0,1]、[1,2]做点积。
- 得到原始分数[3,2,5]，还没有缩放或Softmax。

> 一个Q匹配全部K，得到一行原始分数。

**讲者备注**：手算3、2、5。第三行是位置2，使用q_2；分数5还不是概率。此页只做原始点积，不提前引入缩放与Softmax。下一页对每个Q执行同样操作，得到整张矩阵。

$$
s_{2,j}=\mathbf q_2\cdot\mathbf k_j
$$

```python
raw_row = q[-1] @ k.T
```

## 12．每个位置，都有一行匹配分数（35–38分钟）

矩阵乘法 Q @ K.T，把所有查询的点积一起算出来。
- 每个Q匹配全部K，三个查询得到三行。
- 单元格(i,j)为q_i与k_j点积。
- 喜欢查询喝：[0,2]·[1,2]=4。

> 点积矩阵同时计算所有位置之间的匹配，形状为 T×T。

**讲者备注**：高亮第三行接上一页。请学生指认第二行第三列。Q[3,2]乘K.T[2,3]得[3,3]。原始分数[[1,0,1],[2,2,4],[3,2,5]]不必对称，Q/K投影不同。

$$
\mathbf S_{\rm raw}=\mathbf Q\mathbf K^\mathsf{T}
$$

```python
raw_scores = q @ k.T
```

## 13．为什么要缩放点积分数？（38–41分钟）

先看数值的变化，再理解缩放怎样影响 Softmax 的集中程度。
- 点积累加d_k个乘积，典型波动可能随维度增大。
- 分数差大，Softmax易集中在少数项。
- 缩放保持排序，缓和同一行的集中程度。

> 缩放控制分数尺度，使 Softmax 更适合训练。

**讲者备注**：比较[.114,.042,.844]与缩放后[.178,.088,.734]。方差推导只作追问：分量独立、零均值、单位方差且乘积项互不相关时，点积方差d_k，除sqrt(d_k)后1。

$$
\mathbf S=\frac{\mathbf Q\mathbf K^\mathsf{T}}{\sqrt{d_k}}
$$

```python
scores = raw_scores / math.sqrt(q.shape[-1])
```

## 14．算“喜欢”时，不能提前看到“喝”（41–44分钟）

用因果 Mask 限制可读范围，再在每一行可见的位置之间做 Softmax。
- 位置i可读j≤i。
- 未来分数设-inf，指数为0。
- 保留对角线：当前输入预测下一token。

> Softmax 前把未来分数设为 −∞，其读取权重就变为零。

**讲者备注**：问第二行为什么不能读第三列。未来分数设0不等价，因为exp(0)=1。每行保留至少一个可读位置。padding和全屏蔽行留完整实现时再处理。

$$
\mathbf A=\operatorname{softmax}_j(\mathbf S+\mathbf M)
$$

```python
future = torch.ones(3, 3, dtype=torch.bool).triu(1)
masked = scores.masked_fill(future, -torch.inf)
```

## 15．用权重把 V 合成新的向量（44–47分钟）

A 决定每个位置读多少，V 提供内容，Z = A @ V 得到汇总结果。
- 第一行[1,-1]。
- 第二行[1.5,-0.5]。
- 第三行约[2.555,-0.912]。

> Attention 输出 Z=AV：每行是结合可见上下文后的新向量。

**讲者备注**：手算0.5[1,-1]+0.5[2,0]=[1.5,-.5]。每个query独立在key间分配比例。Z可含负分量，行和无需1。[3,3]@[3,2]得到[3,2]。 算完后追问：如果提供内容的V变了，读取比例会不会跟着变？下一页直接修改刚才的V，继续解释同一过程。

$$
\mathbf Z=\mathbf A\mathbf V
$$

```python
weights = masked.softmax(dim=-1)
output = weights @ v
```

## 16．“我”的 V 变了，哪些结果会变？（47–49分钟）

沿用刚才的矩阵，只改被读取的内容，检查“匹配”和“内容”的区别。
- V[0]由[1,-1]改为[3,-1]。
- Q/K不变，权重不变。
- 各行输出变化为A_i0×[2,0]。

> 固定 Q/K：权重不变，输出随 V 的变化而变化。

**讲者备注**：用clone保留基线。三行输出变化[2,0]、[1,0]、约[.357,0]。直接改V用于控制变量；改X通常同时影响Q/K/V。 接第9页Q/K/V分工的提问。请先猜不变的量，再运行Notebook实验06。

$$
\Delta\mathbf z_i=A_{i,0}\Delta\mathbf v_0
$$

```python
changed_v = v.clone()
changed_v[0] += v.new_tensor([2., 0.])
changed = attention(q, k, changed_v)
```

## 17．“我”的 K 变了，读取比例怎样变？（49–51分钟）

这次保留 V，只改变参与匹配的 K，比较同一查询的分数、权重与输出。
- K[0]由[1,1]改成[2,1]。
- 第三行第0项原始分数3变4。
- 该位置读取权重约0.178变0.306。

> 固定 Q/V：修改 K 可以改变匹配分数、读取权重与输出。

**讲者备注**：重点看第三行。第一行仅可读自身，权重仍[1,0,0]；第二行q=[0,2]与改变量[1,0]正交，分数和权重不变。不可说改K必改变每行。 接着把修改对象从V换成K，观察变化从匹配分数开始，顺着权重传到输出。

```python
changed_k = k.clone()
changed_k[0] += k.new_tensor([1., 0.])
changed = attention(q, changed_k, v)
```

## 18．改动“喝”，前两个位置会受影响吗？（51–53分钟）

改最后位置的输入，把有 Mask 和无 Mask 的结果放在一起比较。
- X[2]由[1,1]改成[4,-1]。
- 开mask：前两行不变，最后变化。
- 关mask：较早行也会受影响。

> 因果 Mask 使较早输出不受未来输入改动影响。

**讲者备注**：参数与位置序号固定。前两行Q没变，可读K/V没变，未来列始终被屏蔽。mask开前缀最大差0，无mask对照约2.794。Notebook在真实RoPE接口重验。 接着检验第14页的因果约束。页面直接比较输出向量；左侧前两行完全一致，右侧前两行改变。

```python
changed_x = x.clone()
changed_x[-1] += x.new_tensor([3., -2.])
q2, k2, v2 = project(changed_x)
```

## 19．将刚才的计算写成程序（53–55分钟）

沿着投影、分数、Mask、Softmax、加权汇总，逐行对应前面的矩阵。
- 三个可训练投影生成Q/K/V。
- 分数缩放、mask、最后一维归一化。
- weights@v得到输出。

> 每行核心代码，都对应刚才算过的矩阵或向量。

**讲者备注**：让学生指认dim=-1是key轴。若dim=0是按列分配权重，不符合每query的读取分布。真实RoPE分支在点积前旋转Q/K。

```python
q, k, v = x @ w_q, x @ w_k, x @ w_v
scores = q @ k.T / math.sqrt(q.shape[-1])
future = torch.ones(3, 3, dtype=torch.bool).triu(1)
masked = scores.masked_fill(future, -torch.inf)
weights = masked.softmax(dim=-1)
output = weights @ v
```

## 20．多个头，分别计算几组匹配（55–57分钟）

每个头各用一组投影参数；计算完后拼接，再通过输出投影合并信息。
- 独立结构示意D4、H2、每头2维。
- 各头投影参数不同，权重可不同。
- 拼接与W_O后输出宽度回到4。

> 多头使用不同投影并行汇总，再拼接并经过输出投影。

**讲者备注**：结构示意换B1T3D4H2dh2。所有头权重[1,2,3,3]，合头[1,3,4]。两头不是预测两个token，不给头预设语法语义角色。

$$
\operatorname{MultiHead}(\mathbf X)=\operatorname{Concat}(\mathbf Z^{(1)},\ldots,\mathbf Z^{(H)})\mathbf W_O
$$

## 21．这张注意力矩阵说明了什么？（57–60分钟）

解释一行权重，算一个输出，再判断修改中间量会影响哪里。
- “喜欢”只能读取我与喜欢，未来喝的权重为0。
- 用第二行0.5[1,-1]+0.5[2,0]，得到[1.5,-0.5]。
- 只改V不改A；改K可能改变A，实际影响取决于Q和可读范围。

> 能读懂矩阵并解释干预结果，就能继续组装完整 Block。

**讲者备注**：参考回答：行是query，列是key；第二行读我和喜欢，因果mask屏蔽喝。输出[1.5,-0.5]。只改V不改变A；只改K可能改变匹配分数和A，本例仅第三行改变。若混淆权重与词概率回第4页，汇总不清重算第15页。后续第四课实现多头、输出投影、残差、Norm、FFN。
