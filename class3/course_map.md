# 第三课课程地图

```text
第一课：文字 → 向量 → 一次注意力 → 候选预测
第二课：BPE → Embedding参数学习 → 位置与RoPE
第三课：复习 → 可训练Q/K/V → 完整单头因果Attention
第四课：多头 → 输出投影 → 残差、Norm、FFN → 完整Block
第五课：错位标签 → 交叉熵 → 训练与验证 → 小语言模型
第六课：自回归生成 → 温度、top-k/top-p → KV cache
```

第三课前14页、25分钟恢复前两课，后续页把Attention从一行扩展为完整矩阵。

| 阶段 | 输入 | 输出 | 本课重点 |
|---|---|---|---|
| 查表 | token IDs | X[T,D] | 输入来自Embedding |
| 投影 | X与三张W | Q/K[T,d_k]、V[T,d_v] | 参数与动态结果的区别 |
| 匹配 | Q/K | 分数[T,T] | 行query、列key |
| 可读范围与归一化 | 分数、mask | 权重A[T,T] | 未来为0，每行和1 |
| 内容汇总 | A和V | Z[T,d_v] | 各位置得到上下文向量 |

标准RoPE在Q/K生成后旋转，再做点积；相加式PE在输入端相加。
主手算例使用T3、D2；第35页多头图使用独立的B1、T3、D4、H2配置。

第四课沿用这里的点积与加权公式，增加batch、head维、拼接和W_O，再组装Pre-Norm Block。
第五课接LM Head和下一token标签，以训练与验证损失检查学习。
第六课观察生成中的重复计算，再解释KV cache如何减少计算。
