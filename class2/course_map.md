# 第二课机制地图

## 输入链路与两类学习

```text
本地语料
  ↓ pair 统计、贪心合并（离散算法）
tokenizer.json：预切分 + 字节词表 + merges + 特殊符号
  ↓ 固定配置 encode
token ID [B,T]
  ↓ gather 参数表 E[V,D]
输入向量 X[B,T,D]
  ↓ 位置接口，选择对应分支
相加式：X + P             RoPE：X → Q/K → 成对旋转
  ↓
Attention / 后续网络
  ↓ 任务误差、反向传播、优化器（连续参数学习）
更新 E 与网络参数
```

tokenizer 的统计规则学习，与神经网络的梯度参数学习，是两套过程。

## 四个实验

| 实验 | 输入与输出 | 验证什么 |
| --- | --- | --- |
| BPE 算法 | 字符片段 → 按 rank 编码 | 编码不等于最长前缀匹配 |
| 真实 ByteLevel | 文本 → 320/384 配置的 ID | 配置、预切分、字节与长度 |
| Embedding / bigram | ID → [N,16] → [N,320] → CE | 梯度与参数真实更新，无 Attention |
| 位置 / Attention 接口 | [2,6,8] → Q/K [2,2,6,4] → [2,6,8] | 旋转、mask、batch 与拆头接口 |

## 形状对照

| 符号 | 含义 | 接口实验 |
| --- | --- | --- |
| B | 句子数 | 2 |
| T | 加起止标记并补齐后的长度 | 6 |
| V | 词表项数 | 320 |
| D | token 向量维度 | 8 |
| H | head 数 | 2 |
| d_h | 每头维度 D/H | 4 |

固定配置下，“我喜欢喝牛奶。”编码为 `[300,304,262]`，加 bos/eos 后5项，补齐至6；“我喜欢喝酒。”本身4项，加标记后6项。pad=0、bos=2、eos=3。

bigram 使用 D=16、57 个相邻 pair，有真实训练；Attention 接口使用 D=8，随机初始化、未训练。这两个实验不能串称为训练好的 Transformer。
