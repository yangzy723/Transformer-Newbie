# 第二课课程地图

## 一条输入链路

```text
输入文字：我喜欢喝牛奶                 6 个汉字
  ↓ 使用本课学好的四条 BPE 规则
token：我 / 喜欢喝牛奶                 2 个 token
  ↓ 使用与模型配套的词表
ID：[4, 11]                           长度 2
  ↓ 从 12×4 的 embedding 表取两行
E[4]  = [ 0.127, 0.448, 0.077, −0.103]
E[11] = [−0.256, 0.074, 0.025,  0.375]
  ↓ 相加式位置机制使用 token 位置 0、1
E[4]  + PE(0)
E[11] + PE(1)                         形状仍是 [2,4]
  ↓
送入后续 Transformer 计算
```

这些切分和初始向量只属于本课的规则与参数。真实模型需使用自己的 tokenizer 与 embedding 表。采用 RoPE 的模型会在后续 Q/K 中引入位置，不直接照搬以上相加步骤。

## 三件事分别由什么决定？

| 问题 | 决定因素 | 本课实验 |
| --- | --- | --- |
| 为什么这样切分？ | 算法、训练语料、词表规模、预处理和固定规则 | 四轮 BPE，频次 10、10、8、8 |
| 为什么查到这些数？ | ID 决定行号，训练改变表行数值 | 12×4 查表；独立的 4×2 分类更新 |
| 怎样表示位置？ | 明确的位置索引和位置机制 | 四维正弦编码；二维 RoPE 验证 |

token ID 不编码位置；输入 embedding 不自动携带当前句子中的位置；因果 mask 规定可读范围，也不等于给出了显式绝对位置编码。
