# 第二课机制实验运行记录

Python 3.13.5 / Tokenizers 0.22.2 / PyTorch 2.14.1，CPU。使用仓库内固定配置，无预训练权重。

## 关键结果

- ByteLevel：Hello world! 在320/384配置下为9/5个token；中文样例均为3。
- lookup与one-hot前向相同；重复行梯度累加；padding lookup梯度为零。
- 手算交叉熵梯度与autograd一致。
- bigram：loss约5.7565→0.3559；26行发生更新；经验条件熵下界约0.35583。
- RoPE：向量范数保持，固定q/k内容整体平移位置后点积相同。
- 接口：[2,6]→[2,6,8]→Q/K[2,2,6,4]；未来和padding key权重均为零。
